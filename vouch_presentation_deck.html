Forensic Depth

Multi-Layer Automated Threat Inspection

Every incoming message undergoes 6 simultaneous forensic verifications before reaching the human eye.

🛡️ Layer 1: Brand Impersonation

Flags display names claiming trusted brands (PayPal, Chase, Apple) when coming from unauthorized domains.

🌐 Layer 2: Google Safe Browsing API

Real-time query against Google's global malware, phishing, and social engineering threat list.

⏱️ Layer 3: ICANN RDAP Domain Age

Live registry verification: Newly Registered Domains (NRDs) under 30 days old are automatically flagged.

🔗 Layer 4: Spoofed Link Inspector

Compares visible anchor text against actual destination domains and checks for bare IP URLs.

↩️ Layer 5: Reply-To Redirection

Spots covert redirection attacks that silently route user replies to an external attacker's inbox.

🤖 Layer 6: Conversational AI Synthesizer

Synthesizes forensic indicators into warm, friend-to-friend advice with OpenAI gpt-4o-mini & heuristics.

The Security Breakthrough

The "Trust, But Verify" Defense Matrix

User trust silences repetitive false alarms—but NEVER blinds our engine to concrete technical attack signals.

When Senders Are Clean (Vouched Safe)

When you vouch for recurring vendors, newsletters, or partners:

  • Soft Urgency Silenced: Repetitive warnings ("Action required on invoice") are quieted.
  • Peace of Mind: Inbox remains green with an authoritative checkmark: "Vouched as safe by you".
  • Exact Address Anchor: Trust is anchored to the EXACT sender address and thread, not entire generic domains.
Hard Attack Signals Override Trust

If a trusted contact's account is hijacked or sends weaponized links:

  • Malicious Links Detected: Google Safe Browsing hits immediately sound an alarm.
  • Anchor Text Disguise: If a link displays bank.com but routes to a phishing site, Vouch overrides.
  • Clear Warning Context: Warns: "You marked this sender safe before, but this email has new dangerous warning signs."
